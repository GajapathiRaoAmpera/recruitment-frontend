Problem 2: LRU Cache with Expiring Time-to-Live (TTL)

Medium Difficulty 100 Points timer 2.0s Limit memory 256 MB

Design and implement a deterministic data structure that follows the constraints of a Least Recently Used (LRU) cache with an integrated Time-to-Live (TTL) eviction policy.

In standard high-throughput telemetry pipelines (such as Ampera Fleet Analytics), nodes cache edge sensor observations. Cached entries remain valid only for ttl milliseconds after their last update or creation. Accessing an expired key must behave identically to a cache miss.

Interface Specification
  • code
    LRUCacheWithTTL(capacity: int)

    Initializes the cache object with positive capacity constraint.

  • code
    get(key: int, current_timestamp: int) -> int

    Returns the positive value if valid and not expired. If key does not exist or has expired (current_timestamp > expiry), evict it and return -1. Updating an access marks it as most recently used.

  • code
    put(key: int, value: int, ttl: int, current_timestamp: int) -> None

    Inserts or updates the key value pair with fresh expiration current_timestamp + ttl. If keys exceed capacity, invalidate the least recently used unexpired entry.

from collections import OrderedDict
import typing

class LRUCacheWithTTL:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.store = OrderedDict()  # key -> (value, expiry_timestamp)

    def get(self, key: int, current_timestamp: int) -> int:
        if key not in self.store:
            return -1
        
        val, expiry = self.store[key]
        if current_timestamp > expiry:
            del self.store[key]
            return -1

        self.store.move_to_end(key)
        return val

    def put(self, key: int, value: int, ttl: int, current_timestamp: int) -> None:
        # Invalidate expired records or evict LRU
        if key in self.store:
            self.store.move_to_end(key)
        self.store[key] = (value, current_timestamp + ttl)
        if len(self.store) > self.capacity:
            self.store.popitem(last=False)
