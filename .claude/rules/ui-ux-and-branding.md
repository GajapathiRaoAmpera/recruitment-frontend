# UI/UX and Branding Rules

- The Stitch mockups in stitch_ampera_campus_recruitment_platform/ and ampera_campus_hire/DESIGN.md are the source of truth for layout, tokens and brand.
- If a screen has no mockup, compose it from existing components and tokens; ask before inventing a new visual style.
- Centralize design tokens; do not scatter arbitrary colors or one-off styling.
- Keep interfaces responsive, accessible, keyboard-friendly, and consistent.
- Support loading, empty, error, success, disabled, permission-denied, and locked/expired-attempt states.
- Use charts only when they communicate real, labeled information.
- Clearly label demo data and simulated integrations.
- Avoid excessive animation and respect reduced-motion preferences; no animation inside the student test screens.
- Preserve logo aspect ratio and clear space.
